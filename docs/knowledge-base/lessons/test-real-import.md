# 测试基础设施与变异测试经验规约 (Testing Lessons & Best Practices)

> **核心原则**：测试是质量生命线，但弱断言与镜像测试会产生虚假的“假绿”。单元测试必须直连真实源码并 Mock 端口；测试环境必须严格隔离复位；必须以变异测试审计断言有效性。

---

## 1. 真实源码导入原则（严禁镜像副本测试）

**反模式**：早期测试图省事在测试文件内手写业务算法（如哈希计算、自愈规则、清洗逻辑）副本来验证。测试全绿但真实代码从未执行，甚至因为手写副本与真实逻辑口径分叉而产生严重盲区。
**规范要求**：
1. 单元测试必须导入真实 TS 源码（通过 Node.js `--experimental-transform-types` 与 `test/register.mjs` 钩子解析，直连真实文件）；
2. 宿主依赖（如 `vscode` 模块）统一重定向至 `test/mocks/vscode.mock.mjs`，严禁在测试中重新实现被测领域逻辑；
3. 测试通过依赖注入（Mock 端口）验证真实领域实体与服务，发现生产代码的隐藏缺陷。

---

## 2. 测试现场严格隔离与还原原则 (Hermeticity Guard)

**反模式**：测试用例直接读写工作区公共文件（如 `.vscode/debug-scenes.json`、`.cursor` 等），或修改了全局状态，在用例结束时未完整还原，导致后续依赖空白配置的测试（如 Inlay Hints、自愈测试）产生跨 Suite 级联污染与随机断言失败。
**规范要求**：
1. **沙箱物理路径强一致**：测试中构造的所有场景与断点，其 `file` 路径必须映射到 `test-fixtures/` 中真实存在的文件，严禁编造虚构扩展名；
2. **Setup/Teardown 强制对称还原**：产生写盘或全局状态修改的用例，必须在 `suiteSetup` 保存初始快照，在 `teardown` / `suiteTeardown` 中无条件将磁盘文件还原回盘；
3. **全局 Mock 状态强复位**：在 `__resetMockVscodeState()` 中，除了清空调用历史，必须将 `showErrorMessage`、`showQuickPick` 等高频交互函数复位回初始实现。

---

## 3. 原生 Subpath Imports 路径规约

**反模式**：在深层目录测试中使用 `../../../src/domain/...` 相对路径导入，丑陋冗长且重构移动文件时极易断链。
**规范要求**：
1. 全工程统一使用原生 Subpath Imports：
   - 生产代码：`#src/*`
   - 测试资产：`#test/*`
2. 在 `package.json` 的 `"imports"` 字段声明映射，测试运行器由 Node.js 原生驱动解析。

---

## 4. 单测双模态自执行规范

**反模式**：测试文件仅导出测试执行函数，导致在 Stryker 或命令行单独调试某个单测时，子进程直接 0ms 退出空转，无法单独运行。
**规范要求**：
测试文件末尾必须统一包含入口自执行判断：
```javascript
if (process.argv[1]?.endsWith("<test_file_name>.test.mjs")) {
  runTests();
}
```
确保既能在集中运行器 `test/run-all.mjs` 中批量调用，也能作为独立进程单独调试或供变异测试执行。

---

## 5. 变异测试（Mutation Testing）与强断言设计

**反模式**：传统行覆盖率高（90%+）但断言过于宽泛（只验证返回值是否存在或类型正确），当运算符被突变（如 `>=` 变 `<`、`&&` 变 `||`、加法变减法、`trim()` 被移除）时，测试依然全部假绿。
**规范要求**：
1. **对抗性候选竞争**：构造高相似度的伪候选与真候选同台竞争，严格断言算法锁定真候选，彻底击杀条件逻辑突变；
2. **脏数据边界与属性容错断言**：测试输入必须包含未修整的真实脏数据（首尾空格、反斜杠路径、纯空白字符串、浮点数行号等），严格断言清洗后的规范属性，击杀字符清洗与类型防御变异；
3. **消除过度工程等价变异体**：数学上恒成立的冗余分支与死代码会滋生无法杀死的等价变异体，应遵从 KISS 原则坚决移除。

---

## 6. 防回环定时器状态泄露教训

**反模式**：`echoLoopGuard.markInternalSaving(600)` 会在进程内维持 600ms 写盘保护期。在单测集中运行器（`test/run-all.mjs`）中，若前序测试触发了保存，后序测试模拟外部文件变更时，事件会被防回环机制静默吞掉，导致后序测试失败。
**规范要求**：
在涉及外部文件监听触发的单测中，测试开始前必须显式调用 `echoLoopGuard.reset()` 清空写盘保护期，彻底阻断跨用例状态泄露。
